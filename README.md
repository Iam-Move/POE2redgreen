# POE2 Color Blindness Fixer (POE2 적/녹 색약 보정 도구)

Path of Exile 2 (POE2)의 패시브 트리를 보는 데 어려움을 겪는 색약 플레이어를 위한 웹 기반 도구입니다.
빨간색(무기세트 1번 패시브)과 초록색(무기세트 2번 패시브) 선의 색상을 명확하게 구분되는 색(파랑/흰색 등)으로 변환해줍니다.

## 주요 기능

- **🔒 완벽한 보안 (Client-Side Only)**: 이미지가 서버로 전송되지 않습니다. 모든 처리는 브라우저 내에서 안전하게 이루어집니다.
- **✨ 스마트 연결 하이라이트**: 단순한 색칠 놀이가 아닙니다. **메인 루트(노란색 선)와 연결된 선**들만 정확하게 찾아 변경합니다. (고립된 점이나 배경 잡티 무시)
- **🎨 색상 커스터마이징**:
    - **Red (무기세트 1번)**: 기본값 **파란색(Royal Blue)** 으로 자동 변경
    - **Green (무기세트 2번)**: 기본값 **흰색(White)** 으로 자동 변경
    - 원한다면 다른 색으로 직접 변경 가능
- **🎚️ 정밀 조절**:
    - **민감도(Sensitivity)** 90%: 희미하게 빛나는 선까지 놓치지 않고 잡아냅니다.
    - **선 굵기(Thickness)** 0.5px: 너무 두껍지 않게, 딱 보기 좋을 만큼만 살짝 강조합니다.

## 사용 방법

1. **[웹사이트 접속](https://rgb.iammove.com)** (배포된 주소)
2. **이미지 업로드**: 게임 스크린샷(`Win + Shift + S`)을 드래그하거나 `Ctrl + V`로 붙여넣으세요.
3. **즉시 확인**: 오른쪽 미리보기 화면에서 색이 바뀐 것을 확인합니다.
4. **다운로드**: 결과물이 마음에 들면 다운로드 버튼을 눌러 저장합니다.

## 설치 및 실행 (개발자용)

이 프로젝트를 로컬에서 실행하거나 직접 수정하고 싶다면 아래 순서를 따르세요.

### 요구 사항
- Node.js 설치 필요

### 설치
```bash
git clone https://github.com/your-username/poe2-color-fixer.git
cd poe2-color-fixer
npm install
```

### 실행
```bash
npm run dev
```

### 빌드 (배포용)
```bash
npm run build
```
생성된 `dist` 폴더를 GitHub Pages나 Cloudflare Pages에 업로드하면 바로 사용할 수 있습니다.
